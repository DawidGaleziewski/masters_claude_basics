# CLAUDE_MD

We can start claude project with /init. IT will try to understand the project and create the CLAUDE.md file.

## What to put in CLAUDE.md
If you need to repeat something over and over in prompt. Put it in CLAUDE.md.

## Why we want to generate it?
We want claude code to have information on things like: 
- commands to run the project
- tech stack
- how our react state is manage
- how data streams

## good way of knowing what to put into the CLAUDE.md
- remove it. And see where the model will trip
- only put things that actually help the model

## Why claude.md needs to be slim
it goes with prompt therefore more content it has the more usage will go up
